# Employee Management System

A Java-based Employee Management System developed using Java, JDBC, MySQL and AWT/Applet.

## Technologies Used

- Java
- JDBC
- MySQL
- Java AWT / Applet
- File Handling

## Main Features

### Admin
- Admin Login
- Employee Management
- Department Management
- Attendance Management
- Payroll Management
- Reports Management
- Employee Registration Reports
- Attendance Reports
- Payroll Reports
- Excel (.xls) Report Generation

### Employee
- Employee Registration
- Employee Login
- View Profile
- View Department Details
- View Attendance
- View Payroll
- Forgot Password

## Project Architecture

The project follows a layered structure:

- Bean – Data/model classes
- DAO – Database operations
- Controller – Application logic
- Applet – User interface

## Database

MySQL database is used for storing:

- Employee details
- Department details
- Attendance records
- Payroll records

## Reports

The system generates `.xls` reports using Java File Handling and FileWriter.

## Purpose

This project was developed as a college project to understand Java, JDBC, MySQL database connectivity, CRUD operations, file handling and layered application architecture.
